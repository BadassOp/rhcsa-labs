# Linux Fundamentals

An introduction to Linux, its history, architecture, distributions, and common use cases.

## Topics

- **What Is Linux?** — An open-source, Unix-like operating system kernel.
- **History of Linux** — Created by Linus Torvalds in 1991 and developed by a global community.
- **Why Linux?** — Offers flexibility, stability, customization, and powerful system administration tools.
- **Where Linux Is Used** — Servers, cloud platforms, supercomputers, embedded systems, and Android devices.
- **Linux Distributions** — Complete operating systems built around the Linux kernel, such as RHEL, Ubuntu, Fedora, and Debian.
- **Linux Architecture** — The interaction between hardware, the kernel, system libraries, shells, and applications.
- **Virtualization** — Running multiple isolated virtual machines on shared physical hardware.

## Goal

Build a basic understanding of Linux before progressing to practical Linux system administration and RHCSA labs.
