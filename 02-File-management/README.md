# Linux File Management

An introduction to navigating the Linux filesystem, managing files and directories, and working with file contents from the command line.

## Topics Covered

- **Filesystem Navigation** — Navigate directories using `pwd`, `cd`, and `ls`.
- **File and Directory Operations** — Create, copy, move, rename, and delete files and directories.
- **Viewing File Contents** — Read files using `cat`, `less`, `head`, and `tail`.
- **File Discovery** — Locate files and directories using `find` and `locate`.
- **File Content Search** — Search for text patterns using `grep`.
- **Paths** — Understand absolute paths, relative paths, and the current working directory.
- **Links** — Understand hard links and symbolic links.
- **Wildcards** — Match multiple filenames using patterns such as `*` and `?`.
- **Input and Output Redirection** — Redirect command output and combine commands using pipes.

## Learning Objectives

By completing this section, you should be able to:

- Navigate the Linux filesystem efficiently.
- Create and manage files and directories.
- Inspect and search file contents.
- Locate files using command-line tools.
- Understand paths, links, and shell wildcards.
- Perform common file management tasks on RHEL.
