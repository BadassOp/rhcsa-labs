# Linux Process Management

Process management involves monitoring, controlling, and troubleshooting running processes on Linux systems.

## Topics Covered

- **Processes** — Understand running instances of programs.
- **Process Identification** — Understand Process IDs (PID) and Parent Process IDs (PPID).
- **Process States** — Understand running, sleeping, stopped, and zombie processes.
- **Process Monitoring** — Inspect processes and system resource usage.
- **Foreground and Background Jobs** — Manage commands running in the current shell.
- **Signals** — Send signals to control or terminate processes.
- **Process Priorities** — Understand nice values and scheduling priority.
- **Resource Monitoring** — Inspect CPU and memory consumption.
- **Process Troubleshooting** — Identify and investigate problematic processes.

## Important Commands

`ps`, `top`, `pgrep`, `pidof`, `kill`, `pkill`, `jobs`, `bg`, `fg`, `nice`, `renice`, and `free`.

## Learning Objectives

- Identify and inspect running processes.
- Understand process IDs and common process states.
- Monitor CPU and memory usage.
- Manage foreground and background jobs.
- Send appropriate signals to processes.
- Adjust process priorities when necessary.
- Troubleshoot processes that consume excessive resources or stop responding.

## Scope

This section covers basic process and job management. Service management with `systemctl`, scheduled tasks, and detailed performance troubleshooting are covered separately.

## Goal

Develop practical process-monitoring and control skills for Linux system administration and RHCSA preparation.
